# Project language

- Use English for all project-facing text unless the user explicitly requests
  another language. This includes menus, messages, console output, logs, errors,
  documentation, code comments, docstrings, and test descriptions.
- Conversation with the user may remain in German; this does not change the
  project's English-language default.
- Preserve user-defined names, identifiers, imported source data, and language
  recognition keywords. Do not translate these as if they were interface text.
